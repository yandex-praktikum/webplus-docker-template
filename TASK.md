# Пример задания
В репозитории в папке my-app содержится код сервиса, который необходимо докеризировать (собрать docker-образ содержащего сервис)
Для этого допишите необходимые инструкции в Dockerfile

Выполните следующие условия:
- Рабочая директория /my-awesome-app
- Запуск проекта происходит через pm2, который устанавливается в качестве глобального модуля
- В Dockerfile указано какой порт использует сервис по-умолчанию.
- Установка зависостей происходит в ci-режиме (по лок-файлу). Используйте соответствующий флаг pnpm для этого
- Корректно работает кэширование зависимостей. 

Для этого необходимо разнести инструкции:
- копирования файлов package.json и package-lock.json и установки зависимостей 
- копирования остальных файлов проекта.
Также не забудьте, что порядок инструкций также имеет значение и может ломать кэш.

Наглядно проверить работу кэширования просто - соберите образ, затем измените любой файл прооекта и запустите сборку повторно. 
Если вы все сделали правильно - этап с установкой зависимости будет пропущен и образ соберется практически мгновенно

- В качестве команды запуска для приложения указана команда запуска проекта через pm2 (используется файл ecosystem.config.js)
- Сервис доступен на порту 3010 и GET запрос на / возвращает строку "Тест пройден!"
- Количество слоев в образе не превышает 6
Проверить количество слоев можно следующим образом: `docker image inspect <(id) или (имя образа:тег)> -f '{{.RootFS.Layers}}' | wc -w`
